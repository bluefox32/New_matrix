# New_matrix

A multi-dimensional additive vector encoder in Python, using exact fractions and the Cayley-Hamilton method: vectors are composed additively and decoded exactly through a matrix inverse, so repeated additions accumulate no restoration error. Fraction and Pythagorean verification scripts are included.

## Contents

- `additive_vector_encoder_v2.py` - Main implementation.
- `ch_fraction_verify.py`
- `pythagorean_vector_encoder.py`
